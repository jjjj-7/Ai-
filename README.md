# AI Terminal Autopilot

运行在 Android 手机上的全自动化 AI 编程工具。AI 直接操控一个连接设备系统的真实终端，通过"规划 → 命令注入 → 输出回读 → 失败修正"的自动驾驶循环，把一句自然语言任务自动推进到完成。

## 与桌面端 AI 编程产品的差异

| 维度 | 常见产品 | 本工具 |
|------|---------|--------|
| 运行位置 | 桌面 IDE / CLI | Android 手机 |
| 执行通道 | 对话补全 + 人工粘贴 | 真实 PTY 终端，AI 自主执行 |
| 交互模式 | 逐步确认 | 全自动循环 + 高危拦截 + 轮数上限 |
| 模型绑定 | 固定厂商 | 用户自配任意 OpenAI 兼容服务 |

## 核心能力

- **完整终端**：自研 PTY JNI 层 + ANSI 渲染器，多会话管理
- **Linux 用户态环境**：首次启动自动从 Termux APT 镜像拉取 bash/coreutils/git/clang/python/node 并解压到应用私有目录（免 root）
- **Agent 自动驾驶**：结构化计划 JSON → 逐步执行 → 观察反馈 → 失败自动修复，默认 50 轮上限
- **安全边界**：高危命令规则引擎（递归删除/块设备写入/fork 炸弹等）命中即暂停人工确认；全部命令入审计日志
- **权限分层**：沙箱级（默认可用）→ 存储级（所有文件访问）→ Shell 级（Shizuku 无线调试授权），高通道不可用自动降级

## 构建要求

- JDK 17、Android SDK 34、NDK（CMake 3.22.1）
- `./gradlew :app:assembleDebug`
- minSdk 26 / targetSdk 34 / arm64-v8a + x86_64

## 使用流程

1. 首启接受风险提示 → 等待用户态环境安装完成
2. 设置页填写 API 地址 / 密钥 / 模型名
3. 终端页输入任务目标（可附验收标准）→ 启动自动驾驶
4. 高危命令弹出时选择放行或拒绝；完成后查看变更清单报告
